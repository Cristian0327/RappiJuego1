# Herramientas conservadas

El juego se abre y edita desde RappiJuego1. Estas utilidades no se ejecutan durante el juego.

- `exportar_modelos_sin_rig.py`: exporta el protagonista, NPC y locales desde los modelos fuente de outputs a la carpeta vecina sin rig. Se ejecuta con Blender, no con Unreal.
- `blueprint_graph.py`: biblioteca de autoría de grafos para el editor de Unreal. No contiene las reglas del juego; estas se guardan como recursos Blueprint dentro de Content.

Los parches históricos, pruebas, registros y compilaciones temporales se retiraron. Para modificar el juego, consulta RappiJuego1/Docs/BLUEPRINTS.md.
